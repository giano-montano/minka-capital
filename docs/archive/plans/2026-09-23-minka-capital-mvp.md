# Minka Capital MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Stellar Testnet prototype where allowlisted investors fund a simulated Peruvian startup revenue-share offering and claim USDC distributions caused by revenue events.

**Architecture:** Stellar Scaffold supplies a React dApp, a Rust/Soroban workspace, and generated TypeScript clients. A single `minka_market` contract owns offering state, allowlist state, investor units, and claimable balances; its administrator submits idempotent revenue events. The React app reads the typed client and indexes contract events through RPC for the live audit feed.

**Tech Stack:** Rust, Soroban SDK, Stellar CLI, Stellar Scaffold, React, TypeScript, Vite, `@stellar/stellar-sdk`.

**Spec:** `docs/specs/minka-capital-mvp.md`

## Global Constraints

- Use Stellar Testnet only; never request, transmit, or embed a real private key.
- Use the React template generated by `stellar scaffold init`.
- The only payment asset is the Testnet USDC SAC address supplied through environment configuration.
- UI copy must state: “Prototipo en Stellar Testnet. No es una oferta de inversión.”
- No secondary trading, KYC, custody, or real-world financial execution is in scope.
